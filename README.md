# 1.Трассировка автономных систем (задача №1)
## Описание проекта
Консольное приложение для анализа маршрута трассировки с определением автономных систем. Программа выполняет трассировку до указанного узла и определяет для каждого маршрутизатора:
- Номер автономной системы (AS)
- Страну расположения
- Интернет-провайдера

## Зависимости
```bash
pip install requests
```
## Использование
```bash
python as.py <IP-адрес или доменное имя>
```

# 2.Кэширующий DNS-сервер (задача №4)
## Описание проекта
Простой DNS-кеширующий сервер, который:
- Рекурсивно разрешает DNS-запросы
- Кеширует результаты для ускорения последующих запросов
- Поддерживает основные типы запросов (A, AAAA, PTR, NS)
## Зависимости
```bash
pip install dnslib  
```
## Использование
```bash
python DNSCache.py
```
Сервер запускается на порту 53 и обрабатывает входящие DNS-запросы.

# 3. SMTP Email Sender (задача №5)
## Описание проекта
Консольное приложение для отправки электронных писем через SMTP с поддержкой:
- Автоматического определения параметров SMTP-сервера для популярных почтовых сервисов
- Отправки текстовых сообщений и вложений
- Настройки через конфигурационный файл
- Повторных попыток отправки при ошибках
  
## Зависимости
```bash
pip install pyopenssl   
```
## Использование
```bash
python email_sender_SMTP.py
```
Создайте файл config.json в формате:
```json
{
  "connection": {
    "login": "your_email@example.com",
    "password": "your_password",
    "smtp_server": "auto",
    "port": "auto",
    "security": "auto"
  },
  "message": {
    "recipients": ["recipient1@example.com"],
    "subject": "Email Subject",
    "text_file": "message.txt",
    "attachments": {
      "files": ["document.pdf"],
      "folder": "attachments"
    }
  },
  "settings": {
    "encoding": "utf-8",
    "retries": 3,
    "timeout": 30
  }
}
```
